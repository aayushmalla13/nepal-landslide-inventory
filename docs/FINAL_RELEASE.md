## Reviewed corrections

The tracked source is `corrections/article_corrections.csv`. Five reviewed
records correct verified dates or exclude verified foreign, multi-event, or
aggregate articles from canonical construction. The fifth correction resolves
an OnlineKhabar English retrospective about widespread October 2025 landslides
that the automated extractor had dated to October 2026. Deduplication applies
the layer automatically, while `reviewed_corrections_applied.csv` retains
before/after state, evidence, reviewer provenance, and the source hash.

Locked v6 validates the pre-correction article classifier. The corrections are
a transparent post-validation release-QA layer and do not alter or rescore the
frozen evaluation. Event-date performance remains unreported.

Any classifier change after this release requires a new locked test version.
Regenerating the same release from unchanged inputs is allowed; revising v6
labels or prediction artifacts is not.

## Verify a release bundle

```bash
python3 - <<'EOF'
import json, hashlib, os
rel = "data/releases/nepal_landslide_inventory_v0.6.0_v7_20260915"
m = json.load(open(os.path.join(rel, "release_manifest.json")))
bad = [f["file"] for f in m["files"]
       if hashlib.sha256(open(os.path.join(rel, f["file"]), "rb").read()).hexdigest()
       != f["sha256"]]
print("mismatches:", bad or "none")
print("bundle lock:", m["bundle_lock_hash"])
EOF
```
